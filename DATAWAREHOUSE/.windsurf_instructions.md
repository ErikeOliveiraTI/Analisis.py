## 🎓 Exemplo: Aceitar Sugestão

### Cenário

Você está em `data_warehouse.py` e Copilot sugere:

```
💡 Loop pode ser otimizado com list comprehension
```

### Decisão

1. **Revisar:** Copilot mostra antes/depois
2. **Testar:** Rodar testes (Ctrl+Shift+T)
3. **Aceitar:** Clica botão ✓ Aceitar

### Resultado

```python
# Antes
dados = []
for idx, row in df.iterrows():
    dados.append(row.to_dict())

# Depois
dados = [row.to_dict() for _, row in df.iterrows()]
```

✅ **Código melhorado!**
