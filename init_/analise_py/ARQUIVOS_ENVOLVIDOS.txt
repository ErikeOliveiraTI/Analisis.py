FLUXO DE EXECUÇÃO
=================

1. INICIALIZAÇÃO (ao fazer login)
   └─ Windows Startup
      └─ Agendador-Backup.lnk
         └─ iniciar_agendador.bat
            └─ python /z/git/init_/analise_py/backup_scheduler.py

2. MONITORAMENTO (continuamente)
   └─ backup_scheduler.py roda em loop
      └─ Verifica hora a cada 30 segundos
         └─ Se for 17:00: continua
            └─ Se ainda não executou hoje: continua
               └─ Executa bash backup_rede.bash

3. BACKUP (às 17:00)
   └─ backup_rede.bash executa
      └─ Verifica unidade Z
      └─ Cria pasta /z/git/rotina/DD MMM
      └─ Copia Caixa.xlsx
      └─ Copia relatórios
      └─ Registra logs

4. LOGS
   └─ /z/git/rotina/log/scheduler.log
   └─ /z/git/rotina/log/backup_YYYY-MM-DD.log
